How it works

No proxy, no new account, no change to how you work. You pick a model and keep coding.

  1. 01

    Pick the trimmed model

    Every model you already have appears a second time in the chat picker, marked “(compressed)”.

  2. 02

    We trim locally

    Your prompt, instructions and tool descriptions are trimmed on your machine. The same input always trims the same way, which keeps the model's prompt cache effective.

  3. 03

    The reply comes back untouched

    The request goes to the model you chose, on your own subscription. The answer streams back exactly as the model wrote it.

What we never change

Trimming is only worth it if you can trust it. These are hard rules in the code, covered by tests.

  • Your code blocks. Fenced code and inline code in your messages are passed through byte-for-byte, indentation included. TrimWell never edits your files.
  • The model's answers. Replies and earlier assistant turns are never modified.
  • Agent tools. Tool names, parameter keys and allowed values stay exactly as defined.
  • Meaning. “Not”, “never”, “no” and other negations are never removed.

Your prompts stay between you and your model

TrimWell has no server in the request path. Nothing you type is sent to us.

100% local processing

Trimming runs inside VS Code on your machine. Prompt content goes only to the model you selected.

No access to your credentials

We never read, store or send your GitHub sign-in. Model access goes through VS Code's built-in language-model API.

Telemetry off by default

If you opt in, we receive token counts and settings only — never prompt text, file contents, paths or user identifiers.

Questions

How much will we save?

It depends on the model and the work. On Claude Haiku 5.5, coding tasks cost 3–20% less in our benchmark, about 13% on average. Sonnet and Opus are being tested now. The pilot measures it on your own usage report, so you see your number before you decide.

Does it lower our Copilot seat cost?

No. Seat licences are a fixed fee. TrimWell reduces the AI credits used by chat and agents, so developers stay within their budget longer and metered spend above the included credits goes down.

Does it change my code?

TrimWell never edits your files — your assistant makes edits as usual. Code blocks and inline code in your messages are passed through unchanged; only surrounding prose such as instructions, explanations and tool descriptions is trimmed.

Will answer quality drop?

In our benchmark so far, tasks pass the same acceptance tests with and without TrimWell; the sample is still small, and the pilot extends it. [DEFAULT MODE — describe once decided.] You can switch back to the untrimmed model at any moment.

What leaves my machine?

Only the trimmed request, sent to the model you picked. Optional telemetry sends token counts and settings — no prompt text, file contents or identifiers.

Does it use our own Copilot subscription?

Yes. TrimWell is local software. Each developer uses their own subscription; we don't provide or resell model access.
